# Farline companion

**English** · [Français](#français)

A Stream Deck plugin and master profiles for **Farline**. Your keys press the game's commands and
show what its HUD shows (speed, convergence, landing gear, energy...), over a connection between the
game and the Stream Deck software **on your own PC**. Nothing leaves your PC.

## Install

1. Download `com.david-digitis.farline-companion.streamDeckPlugin` and double-click it: the Stream
   Deck software installs the **Farline** actions.
2. Download the master profile for your device (`Farline-Mini`, `Farline-Classic`, `Farline-XL`,
   `Farline-Plus`, `Farline-Neo`; `-FR` for French folder names) and double-click it.

## Pair

1. In the game: **Controls > Companion**, tick **Enable the companion**, click **Pair a device**.
   A six-digit code shows, good for two minutes.
2. In the Stream Deck software, click any Farline key: type the code in **Code shown in the game**
   and click **Pair**. Done once; the game remembers this Stream Deck until you revoke it.

## Copy a block

The master profile has one folder per tab of the game's Controls page. Copy the keys you like into
your own profile: they keep working when the game changes, because each key asks the game for its
labels at every connection.

Once the companion is released, the **Guides** page of the game has the details.

## Français

Un plugin Stream Deck et des profils maîtres pour **Farline**. Vos touches appuient sur les commandes
du jeu et affichent ce que montre son HUD (vitesse, convergence, train, énergie...), par une connexion
entre le jeu et le logiciel Stream Deck **sur votre propre PC**. Rien ne sort de votre PC.

### Installer

1. Téléchargez `com.david-digitis.farline-companion.streamDeckPlugin` et double-cliquez dessus : le
   logiciel Stream Deck installe les actions **Farline**.
2. Téléchargez le profil maître de votre appareil (`Farline-Mini`, `Farline-Classic`, `Farline-XL`,
   `Farline-Plus`, `Farline-Neo` ; `-FR` pour les noms de dossiers en français) et double-cliquez dessus.

### Appairer

1. Dans le jeu : **Commandes > Companion**, cochez **Activer le companion**, cliquez sur
   **Appairer un appareil**. Un code à six chiffres s'affiche, valable deux minutes.
2. Dans le logiciel Stream Deck, cliquez sur une touche Farline : tapez le code dans **Code affiché
   dans le jeu** et cliquez sur **Appairer**. Une seule fois : le jeu se souvient de ce Stream Deck
   jusqu'à ce que vous le révoquiez.

### Copier un bloc

Le profil maître a un dossier par onglet de la page Commandes du jeu. Copiez les touches qui vous
plaisent dans votre propre profil : elles restent justes quand le jeu évolue, car chaque touche
demande ses libellés au jeu à chaque connexion.

Une fois le companion publié, la page **Guides** du jeu donne le détail.
